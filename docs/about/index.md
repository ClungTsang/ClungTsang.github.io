# 关于智恩创科科技（深圳）有限公司

智恩创科科技（深圳）有限公司是一家立足深圳、服务大湾区（深圳、香港、澳门）并辐射日本、非洲市场的技术服务公司，专注于 **AI 大模型应用**、**企业级 IT 服务** 与 **RPA 流程自动化** 解决方案。

**公司地址**: 深圳市龙岗区创投大厦 B510  
**公司荣誉**: 创投大厦 · 模力谷 OPC 社区优秀企业

## 我们是谁

我们是一支由全栈工程师、AI 技术专家与跨境业务顾问组成的技术团队。不满足于"外包交付"，我们追求从理解业务痛点出发，用 AI + 自动化的方式为企业创造可量化的效率提升。

::: info 关键数字
- **6+** 个从 0 到 1 的全栈交付项目
- **3** 个市场覆盖（大中华区、日本、非洲）
- **4** 个核心 SaaS/平台产品
- **10+** 企业客户信赖
:::

## 核心能力

### AI 大模型应用 🤖

- GEO（生成式引擎优化）品牌监测与内容策略
- 大模型 API 聚合网关与多模型路由
- AI Agent 自动化工作流（采集、分析、报告生成）
- 企业知识图谱构建与智能检索

### 全栈开发 💻

- 后端：Spring Boot · Spring Cloud · Python FastAPI
- 前端：Vue 3 · Nuxt 4 · TypeScript · Element Plus
- 移动端：H5 响应式 · 微信/支付宝小程序
- 基础设施：Railway · Supabase · Docker · Cloudflare

### RPA 自动化 ⚡

- 来也科技 RPA 产品深度合作伙伴
- 办公流程自动化（报表、对账、数据录入）
- 跨系统端到端流程设计与落地
- 制造业、财务、电商场景实战经验
