# 关于智恩创科科技（深圳）有限公司

智恩创科科技（深圳）有限公司是一家立足深圳、服务大湾区（深圳、香港、澳门）的技术服务公司，专注于企业级 IT 服务与 RPA 流程自动化解决方案。

[[toc]]

## 我们是谁

::: info 公司简介
我们把自己定位为「懂业务的技术伙伴」，而不是单纯的外包团队。
无论是 IT 系统还是 RPA 机器人，最终都要回到一个核心：**让企业运行得更稳、更快、更省心。**
:::

### 核心关键字

- 🧠 深入理解业务流程再谈技术方案
- 🤝 以长期合作为目标，而非一次性专案交付
- 🌏 聚焦大湾区企业的实际场景与合规要求

## 我们的定位

- 以技术为核心，帮助企业提升运营效率与数据价值
- 将复杂的系统与流程抽象为可持续演进的数位资产
- 陪伴企业从「没有系统」走向「善用系统」与「持续优化」

## 核心能力

### IT 服务 💻

- 企业官网与品牌展示平台规划与落地
- 业务系统与后台管理平台的设计与开发
- 系统整合、性能优化与安全加固

### RPA 自动化 🤖

- 办公流程机器人（如报表整理、资料录入、定期稽核）
- 财务、人力、运营等部门重复性工作的自动化
- 与既有系统（ERP、CRM 等）整合的端到端流程设计

::: tip 为什么选择我们？
- 同时懂产品、技术与业务流程
- 重视可维护性与交付后的持续运行
- 能用非技术语言与业务部门高效沟通
:::

## 技术与产品基础

### 技术栈

- 🟢 后端：基于 Spring 全家桶打造（如 Spring Boot、Spring Cloud 等），支援高并发与稳定扩展
- 🟣 前端：采用 Vue 主流技术栈构建（如 Vue、Vite 等），兼顾性能与体验

### RPA 产品

- 采用 **来也科技** 的 RPA 产品作为底层平台
- 在此基础上结合企业实际流程进行二次设计与落地
- 兼顾稳定性、安全性与长期可维护性

## 服务区域与客户

我们专注于服务大湾区客户，特别是：

- 深圳及周边制造业与创新型企业
- 香港、澳门的服务业与专业机构
- 有跨区域协同需求的中小企业与成长型公司
