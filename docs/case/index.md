## 核心产品

### OmniGEO — AI 品牌监测 SaaS 平台

面向跨境企业的 GEO（生成式引擎优化）品牌监测平台，覆盖 ChatGPT、Perplexity、Gemini 等主流 AI 搜索平台。

::: info 核心能力
- 品牌 AI 可见性实时监测与竞品对比分析
- AI 平台引用诊断与内容优化建议
- 多品牌、多市场、多语言支持
- Railway + Supabase 全栈架构，Cloudflare 全球加速
:::

- **访问**: [omni-geo.cn](https://omni-geo.cn)
- **技术栈**: Nuxt 4 · Supabase · Railway · Python 采集引擎 · New API Gateway

---

### CTN Express — 中非跨境电商平台

面向中非贸易的全栈跨境电商平台，支持商品管理、订单处理、多币种结算与物流追踪。

::: info 核心能力
- Spring Boot 微服务后端 + Vue 管理后台
- 多币种汇率实时同步与结算引擎
- MySQL 高并发架构，30+ 数据表、4000+ 商品
- 前后台分离部署，Railway 全托管
:::

- **技术栈**: Spring Boot · Vue 3 · MySQL · Railway · Docker

---

### JP Recycle — 日本买取电商平台

面向日本二手回收市场的在线买取（收购）平台，支持用户在线估价、申请回收、订单追踪全流程。

::: info 核心能力
- Nuxt 4 前端 + Element Plus 管理后台
- 日本市场本地化适配（日语 UI、日元计价）
- 订单状态实时追踪与自动化通知
:::

- **技术栈**: Nuxt 4 · Element Plus · Railway · PostgreSQL

---

### 智能排课管理系统

为成人自考/继续教育学院打造的一体化教务排课管理平台，覆盖学校管理端、排课管理端、学生端、教师端四大角色。

::: info 核心能力
- 智能排课算法，支持教室/教师/课程多维约束
- 四端分离架构，权限精细化管控
- 学生端强制弹窗通知 + 教师端灵活调度
- 完整操作手册 + 产品介绍文档交付
:::

- **技术栈**: Vue 3 · Vite · Element Plus · Canvas 排课可视化

## 合作流程

我们以「理解业务 → 方案设计 → 快速交付 → 持续迭代」为核心理念：

1. **需求沟通** — 了解你的业务场景与核心痛点
2. **方案输出** — 提供 2–3 个可选技术方案与报价
3. **敏捷开发** — 2–4 周出 MVP，快速验证核心价值
4. **持续运维** — 交付后提供技术顾问与系统迭代服务
