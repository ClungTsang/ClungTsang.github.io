## 标杆案例

### 氪金达人 — 澳门头部游戏充值平台

澳门 No.1 游戏点数卡及 Pokemon TCG 交易平台，覆盖日港澳地区，多币种、多仓联动。

::: info 关键数据
- 💰 年营收 **5,000 万+ MOP**
- 🏪 香港 **5 间**实体门店（九龍塘、將軍澳、太子、上水、元朗）
- 🛒 **双平台**：游戏点数卡商城 + Pokemon TCG 零售商城
- 📁 源代码 **9.6 万+** 文件
:::

**核心能力**：
- 🏬 澳门、香港多仓库存实时同步，仓库智能锁定/解锁 + 出库优先级设置
- 🇯🇵 日本收购站 — 深度串接 Zaico 库存 API + eKYC 电子身份验证，支持店面/邮寄/法人三种收购模式
- 🛡️ 高价值卡牌交易多维度风控体系（账号行为分析 + 设备指纹识别）
- 💱 多币种支付集成，财务系统自动化对账

**技术栈**：Vue 3 · Spring Boot · MySQL · 物流 API 集成 · 风控引擎

**服务范围**：全站开发 · RPA 自动化 · 技术运维 · 全套技术搭建/上线/维护

### 丰宾电子 — 制造业全流程 RPA 自动化

鼎捷 ERP 与 SAP 双系统高效协同实战。

::: info 关键成果
- ⚡ 人工操作节省 **70%+**
- 🔄 覆盖应收/应付全流程（对账-开票-冲账闭环）
- 📋 交付完整 SOW 与实施方案
:::

**核心痛点**：鼎捷 ERP 与 SAP 并行，财务需手动比对海量 Excel 数据并完成抛账、立账、冲账等 7 大步骤。

**技术方案**：来也 RPA 定制开发 — 自动登录 ERP 执行 aapt110/160 等 10+ 作业代码；智能匹配采购单与物料号；对接易票云实现发票自动化处理。
