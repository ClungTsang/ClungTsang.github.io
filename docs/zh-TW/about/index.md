# 關於智恩創科科技（深圳）有限公司

智恩創科科技（深圳）有限公司是一家立足深圳、服務大灣區（深圳、香港、澳門）的技術服務公司，專注於企業級 IT 服務與 RPA 流程自動化解決方案。

[[toc]]

## 我們是誰

::: info 公司簡介
我們把自己定位為一個**懂業務的技術夥伴**，而不是單純的外包團隊。
無論是 IT 系統還是 RPA 機器人，最終都要回到一個核心：讓企業運行得**更穩、更快、更省心**。
:::

### 核心關鍵字

- 🧠 先理解業務流程，再談技術方案
- 🤝 以長期合作為目標，而非一次性專案交付
- 🌏 聚焦大灣區企業的實際場景與合規要求

## 我們的定位

- 以技術為核心，幫助企業提升營運效率與資料價值
- 將複雜的系統與流程抽象為可持續演進的數位資產
- 陪伴企業從「沒有系統」走向「善用系統」與「持續優化」

## 核心能力

### IT 服務 💻

- 企業官網與品牌展示平臺規劃與落地
- 業務系統與後臺管理平臺的設計與開發
- 系統整合、效能優化與安全加固

### RPA 自動化 🤖

- 辦公流程機器人（如報表整理、資料錄入、定期稽核）
- 財務、人力、營運等部門重複性工作的自動化
- 與既有系統（ERP、CRM 等）整合的端到端流程設計

::: tip 為什麼選擇我們？
- 同時懂產品、技術與業務流程
- 重視可維護性與交付後的持續運行
- 能用非技術語言與業務部門高效溝通
:::

## 技術與產品基礎

### 技術棧

- 🟢 後端：基於 Spring 全家桶打造（如 Spring Boot、Spring Cloud 等），支援高併發與穩定擴展
- 🟣 前端：採用 Vue 主流技術棧構建（如 Vue、Vite 等），兼顧效能與體驗

### RPA 產品

- 採用 **來也科技** 的 RPA 產品作為底層平臺
- 在此基礎上結合企業實際流程進行二次設計與落地
- 兼顧穩定性、安全性與長期可維護性

## 服務區域與客戶

我們專注於服務大灣區客戶，特別是：

- 深圳及周邊製造業與創新型企業
- 香港、澳門的服務業與專業機構
- 有跨區域協同需求的中小企業與成長型公司
